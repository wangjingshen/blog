## 前言
研发有客户陆续送 larry 靶向文库，现根据官方 10X 样本的分析文档对下机数据进行分析，并整理成脚本，便于后续样本的分析和交付。


## 使用

分析环境：celescope3.0.0

测试目录：/SGRNJ06/randd/USER/wangjingshen/script_dev/larry/test

测试示例：
```
python /SGRNJ06/randd/USER/wangjingshen/script_dev/larry/script/pipeline.py \
    --fq_path /SGRNJ06/randd/USER/wangjingshen/script_dev/larry/test/input/ \
    --library_id test \
    --matrix /SGRNJ06/randd/USER/wangjingshen/script_dev/larry/test/input/test_matrix_10X/test_EmptyDrops_CR_matrix_10X.tar \
    --spname test

```

参数
```
--fq_path              larry 文库 fq 文件路径
--library_id           larry 文库 fq 前缀
--matrix               匹配转录组的 matrix 文件
--spname               样本名
```
