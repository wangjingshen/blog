## 前言
最近测试了 iStar，它基于分层图像特征提取，将空间转录组学（ST）数据和高分辨率组织学图像相结合，以实现超分辨率的空间基因表达预测。原软件是多个python命令单独执行，现整合进一个流程，便于执行，现整理相关内容如下。

## 使用
代码：/SGRNJ06/randd/USER/wangjingshen/script_dev/istar/script/pipeline.py
source activate istar_env

python /SGRNJ06/randd/USER/wangjingshen/script_dev/istar/script/pipeline.py \
    --mapfile mapfile \

#### 参数：
```
mapfile   tsv文件，dir<>image<>pos<>spname
step  需要运行的模块，默认为'input,preprocess,impute,cluster'
threads  线程数，默认为 1
```

mapfile示例
```
spname image dir pos
Mint_FFPE_96_96_1119 /SGRNJ06/randd/PROJECT/R25030501_Spatial_FFPE_tgx/20251127/chang_HE-spatial/figure/20251118_chang.jpeg /SGRNJ06/randd/PROJECT/R25030501_Spatial_FFPE_tgx/20251127/Mint_FFPE_96_96_1119/ /SGRNJ06/randd/PROJECT/R25030501_Spatial_FFPE_tgx/20251127/chang_HE-spatial/tissue_positions_list.csv
```
