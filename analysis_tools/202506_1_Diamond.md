## 前言
研发测试样本有时会受到污染导致 mapping 率较低，需要分析是引入了哪些污染。旧有流程仅针对 celescope v1 版本，且固定取前 10,000 条未比对 reads 进行分析，现对此进行更新，主要更新有：1）增加支持 celescope v2 版本；2）随机抽取自定义条 reads；3）增加输入 mapfile 以进行多样本分析。

## 测试
测试路径：/SGRNJ06/randd/USER/wangjingshen/script_dev/diamond/test，

step1: 默认情况下，celescope 不会输出未比对的 reads, 需要添加 --STAR_param "--outReadsUnmapped Fastx" 重新运行 celescope;

step2: 提供 mapfile，运行 diamond。
```
source activate r4.1_dev
python /SGRNJ06/randd/USER/wangjingshen/script_dev/diamond/script/diamond.py \
    --mapfile mapfile
```

更新后的脚本只需要提供一个两列的 mapfile, 样本名（sample）和抽取的 reads 数（n_reads）。
```
sample n_reads
s1 10000
s2 10000
```
